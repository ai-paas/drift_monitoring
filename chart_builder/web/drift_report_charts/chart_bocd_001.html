t=18에서 change point probability가 0.87로 가장 높고, t=27에도 보조 peak가 나타나는지 읽는다.

런 길이 사후분포

t=18 변화점 후보에서 run length가 낮은 값으로 reset되는지 확인한다.

스트림 추세

stream 평균이 0.55에서 0.87, 다시 1.10 수준으로 이동하는지 본다.

해석

BOCD는 매 시점의 change point probability와 run length posterior를 갱신한다. 이 예시에서는 t=18에 posterior가 집중되고 run length가 reset되며 stream 수준이 0.55에서 0.87로 올라간다. t=27의 보조 peak와 추가 상승까지 함께 보이면 stream segment가 두 차례 바뀐 BOCD 기반 drift 후보로 해석한다. 단, 변화 원인과 모델 성능 영향은 별도 feature, segment, label 분석으로 확인해야 한다.
