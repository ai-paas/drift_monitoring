# Component Guide: Notes, Legend, And Context-Only Components

Some `domain_specific_visual`, notes, legend, or text components are visible but are not graph or table evidence.

For these components:

- State that the component is a supporting notes/context area.
- Do not require numeric evidence if the component only contains explanatory text.
- Do not use it as the main reason for a drift judgment.
- A non-LLM fallback provider is acceptable when the note correctly says the area is not primary graph evidence.
