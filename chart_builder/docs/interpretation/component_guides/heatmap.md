# Component Guide: Heatmap

Explain heatmaps as a value matrix over two axes.

Mention:

- x-axis meaning and y-axis meaning,
- value field or values array that controls color intensity,
- strongest cell or band and its coordinate,
- whether high values form a narrow spike, broad block, diagonal/run pattern, or repeated secondary cluster,
- configured markers or annotations that align with high-intensity cells.

For posterior/probability heatmaps, describe concentration and reset behavior, not just color. Do not call a high cell a confirmed drift unless the chart rule or companion components support that decision.
