# Component Guide: Reference/Current Comparison

Explain comparison components as side-by-side values by metric, category, feature, segment, or window.

Mention:

- category or metric rows,
- series labels such as reference/current or champion/challenger,
- absolute values and deltas,
- direction of improvement or degradation when the metric defines it,
- operational tradeoffs such as latency or cost when present.

Do not call a larger value better or worse unless metric direction is explicit.
