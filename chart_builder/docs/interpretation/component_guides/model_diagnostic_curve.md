# Component Guide: Model Diagnostic Curve

Explain diagnostic curves such as ROC, calibration, or precision-recall as model-separation evidence.

Mention:

- x-axis and y-axis meaning,
- whether a reference diagonal or null curve is present,
- curve position relative to the reference,
- important annotation such as AUC,
- point or region where separation is strongest.

For domain-classifier ROC curves, high AUC means the classifier can distinguish baseline/current periods. It is drift evidence, not root-cause evidence.
