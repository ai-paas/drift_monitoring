# Component Guide: Forest Plot

Explain forest plots as an effect estimate with uncertainty.

Mention:

- value field, low field, and high field,
- point estimate,
- interval bounds,
- null reference value,
- whether the interval includes or excludes the null,
- practical caution when the interval is wide.

Do not present an odds ratio or risk ratio as causal proof. It is association evidence unless the chart supplies causal design context.
