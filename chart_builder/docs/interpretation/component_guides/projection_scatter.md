# Component Guide: Projection Scatter

Applies to `projection_scatter` and similar 2D embedding/projection views.

Explain:

- each point as a sample or window projected to x-y space,
- x/y projection axes,
- color or group meaning such as baseline/current/outlier/class,
- cluster location, overlap, separation, and concentration,
- whether outliers are random or concentrated in a specific current region.

Projection separation can support a drift hypothesis, but it does not identify root cause or class drift without additional evidence.
