# CHART-MV-003 Guide

This chart explains density-ratio or LSDD-style multivariate drift through a density-difference matrix, LSDD trend, and null distribution.

Read in this order:

1. Summary card: LSDD/statistic value, p-value, and decision or status.
2. Matrix view: cells or bins with increased/decreased density and their row/column meaning.
3. LSDD trend: window-level statistic movement and threshold or recent peak if present.
4. Null histogram: observed statistic position relative to the null distribution.
5. Notes/legend: use as supporting context only.

The chart-level interpretation should name where current density increased and where reference density decreased, then link that spatial pattern to the LSDD trend and null evidence. Do not claim root cause unless the notes explicitly provide it.
