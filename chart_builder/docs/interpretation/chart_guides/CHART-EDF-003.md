# CHART-EDF-003 Guide

This chart explains Cramer-von Mises style distribution change through repeated CDF differences and cumulative squared difference.

Read in this order:

1. Summary card: CvM statistic, approximate p-value, and cumulative area.
2. CDF comparison: reference/current CDF separation across value ranges.
3. Cumulative curve: where squared CDF difference accumulates fastest.
4. Notes/legend: use as context only.

The chart-level interpretation should connect multiple value-range CDF gaps, the cumulative increase after the median region, CvM statistic, and p-value.

Do not focus only on one maximum gap; unlike KS, this chart emphasizes accumulated differences.
