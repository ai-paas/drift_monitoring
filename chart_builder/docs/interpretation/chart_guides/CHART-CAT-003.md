# CHART-CAT-003 Guide

This chart explains categorical drift using L-infinity distance: the largest single category proportion change.

Read in this order:

1. Summary card: L-infinity value, max category, and signed direction.
2. Proportion grouped bars: the highlighted max-change category and important secondary category changes.
3. Max-delta ranking: largest absolute category movements and signed labels.
4. L-infinity trend: whether the latest value exceeds the management threshold.
5. Notes/legend: use as context only.

The chart-level interpretation should emphasize that search decrease is the largest single-category movement, while purchase increase is a secondary movement. Explain that L-infinity differs from Total Variation because it focuses on the maximum category delta rather than total probability mass movement.

Do not claim the reason for the search decrease from this chart alone. Check traffic source, campaign, logging, and segment composition before assigning cause.
