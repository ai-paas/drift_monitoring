# CHART-PROB-003 Guide

This chart explains reduced overlap between reference and current probability distributions.

Read in this order:

1. Summary card: overlap, distance, or decision value.
2. Distribution bars: reference/current bin probabilities and where mass moved.
3. Overlap bar: overlap and missing/non-overlap share.
4. Distance trend: Bhattacharyya, Hellinger, or configured distance over windows.
5. Notes/legend: use as supporting context only.

The chart-level interpretation should connect right/left movement in bin probabilities with overlap loss and distance trend. Avoid treating low overlap as root cause; it is distributional evidence that needs segment and sampling checks.
