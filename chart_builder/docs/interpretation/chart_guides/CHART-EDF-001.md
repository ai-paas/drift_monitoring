# CHART-EDF-001 Guide

This chart explains a KS-test distribution shift using empirical CDFs and a histogram.

Read in this order:

1. Summary card: KS statistic, approximate p-value, and sample size.
2. ECDF chart: reference CDF, current CDF, and the maximum vertical gap.
3. Histogram: reference and current bins showing where the distribution moved.
4. Notes/legend: use as context only.

The chart-level interpretation should connect the ECDF maximum gap, rightward movement in the histogram, KS statistic, and p-value. Cite concrete statistic and p-value values from the summary.

Do not claim a root cause from the KS test alone.
