# CHART-DIST-001 Guide

This chart explains a rightward payment-amount distribution shift and increasing Wasserstein distance.

Read in this order:

1. Summary card: Wasserstein distance, mean shift, and upper-tail movement.
2. Distribution overlay: reference density versus current density and where the current distribution moves.
3. Distance trend: window-by-window Wasserstein distance and threshold marker.
4. Feature ranking: which feature has the largest distance.
5. Notes/legend: use as context only.

The chart-level interpretation should connect rightward density movement, increasing recent window distance, and the feature ranking. Use concrete values from the summary, trend, and ranking.

Do not claim fraud, product mix, or user behavior as a cause from distribution distance alone.
