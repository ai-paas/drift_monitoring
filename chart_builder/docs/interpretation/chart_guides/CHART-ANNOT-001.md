# CHART-ANNOT-001 Guide

This chart explains one-sided direction annotation. The main question is whether the declared direction matches the observed difference.

Read in this order:

1. Summary card: declared direction, D+ or D- gap, and one-sided p-value.
2. Direction overlay: baseline/current curves, upper gap marker, lower gap marker, and which direction is counted.
3. Test cards: upper/greater and lower/less decisions, p-values, and counted/not-counted state.
4. Variant usage matrix: which method variants support upper/lower one-sided interpretation.

For an upper one-sided chart, count only evidence where current is larger than baseline in the declared direction. Treat the lower/opposite signal as context unless the declared direction is lower.

Do not interpret a neutral display line as a drift threshold. Do not treat one-sided evidence as two-sided significance.
