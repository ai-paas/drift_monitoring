# CHART-DISTSHAPE-001 Guide

This chart explains distribution-shape drift through density overlay, ECF component differences, and statistic contributions.

Read in this order:

1. Summary card: shape test statistic, p-value, and dominant shape feature.
2. Density overlay: reference versus current density, shoulder, asymmetry, and multimodality.
3. ECF distance view: real and imaginary component differences by frequency.
4. Contribution bars: which frequency contributes most to the statistic.
5. Notes/legend: use as context only.

The chart-level interpretation should connect the visible shoulder or mode change to ECF differences and the largest contribution. Use contribution bars as test-statistic attribution, not as a standalone cause.

Do not reduce the chart to only mean shift; this chart is about shape change.
