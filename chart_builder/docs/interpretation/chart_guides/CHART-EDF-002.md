# CHART-EDF-002 Guide

This chart explains tail-sensitive distribution change through upper-tail ECDF separation and a QQ-style quantile view.

Read in this order:

1. Summary card: AD statistic, approximate p-value, and tail-difference metric.
2. Tail ECDF: where reference and current CDFs separate in the tail.
3. Quantile/QQ view: which current quantiles move away from the reference diagonal.
4. Notes/legend: use as context only.

The chart-level interpretation should connect larger upper-tail values, QQ points moving away from the diagonal, the AD statistic, and the p-value.

Do not describe the shift as uniform if the visible evidence is concentrated in the tails.
