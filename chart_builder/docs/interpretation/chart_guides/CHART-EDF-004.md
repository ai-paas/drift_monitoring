# CHART-EDF-004 Guide

This chart explains circular-distribution drift through signed CDF deviation and angular histogram movement.

Read in this order:

1. Summary card: Kuiper V, approximate p-value, and peak-angle shift.
2. Deviation curve: positive and negative CDF differences and zero baseline.
3. Circular histogram: reference versus current angular mass and peak movement.
4. Notes/legend: use as context only.

The chart-level interpretation should connect D+ and D- style deviations, Kuiper V, p-value, and the angle range where current mass shifts.

Do not interpret angles as linear time. Keep circular wrap-around semantics in mind.
