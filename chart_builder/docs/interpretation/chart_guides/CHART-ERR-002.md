# CHART-ERR-002 Guide

This chart explains RDDM behavior where warning/drift evidence is retained before reactive reset.

Read in this order:

1. Summary card: drift time, reset time, and retained-window size.
2. Error-rate trend: error movement relative to warning and drift thresholds.
3. Retained-window trend: how the retained window changes before and after reset.
4. Comparison timeline: DDM reset versus RDDM retained/reactive-reset behavior.
5. Notes/legend: use as context only.

The chart-level interpretation should connect the error alarm, retained warning window, reset timing, and comparison timeline.

Do not treat reset as recovery unless post-reset error evidence supports it.
