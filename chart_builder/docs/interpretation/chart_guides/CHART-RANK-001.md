# CHART-RANK-001 Guide

This chart explains a rank-position shift using distribution summaries and rank-bin comparison.

Read in this order:

1. Summary card: median/mean rank change, overlap, or status.
2. Distribution summary plot: reference/current low, quartiles, median, high, mean, and density shape.
3. Rank bars: reference/current mass by rank bin and the bins with largest imbalance.
4. Notes/legend: use as supporting context only.

The chart-level interpretation should state whether current ranks moved toward higher or lower positions, using quantiles and rank-bin evidence together. A rank shift is not a root-cause explanation by itself.
