# CHART-PROB-002 Guide

This chart explains categorical probability drift using reference/current category shares, JS/Hellinger trend, and delta bars.

Read in this order:

1. Summary card: JS/Hellinger/statistic value, overlap, or decision.
2. Distribution bars: reference/current share for each category and the largest share changes.
3. Distance trend: JS and Hellinger movement over windows.
4. Delta bars: positive and negative category changes.
5. Notes/legend: use as supporting context only.

The chart-level interpretation should name which categories decreased and increased, then connect those deltas to the distance trend. Do not infer user behavior or business cause beyond the category-share evidence.
