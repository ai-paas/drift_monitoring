# CHART-ERR-001 Guide

This chart explains DDM drift evidence through error-rate trend, warning/drift thresholds, margin, and state timeline.

Read in this order:

1. Summary card: latest error rate, warning time, and drift time.
2. Error-rate trend: error movement relative to warning and drift threshold markers.
3. Margin view: p+s minus drift threshold or equivalent margin crossing.
4. State timeline: normal, warning, and drift intervals.
5. Notes/legend: use as context only.

The chart-level interpretation should connect error-rate increase, threshold crossing, positive margin, and timeline transition.

Do not claim permanent model failure or root cause from DDM alone. Mention sample size, label delay, and class/segment mix as checks.
