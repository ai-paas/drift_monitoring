# CHART-PSI-001 Guide

This chart explains PSI drift by score bin using reference/current proportions, PSI contribution, and PSI trend.

Read in this order:

1. Summary card: total PSI, threshold or status, and largest changed bin if available.
2. Bin bars: reference/current proportion by score bin and direction of change.
3. Contribution bars: bins with the largest PSI contribution.
4. PSI trend: window-level PSI movement and threshold relation.
5. Notes/legend: use as supporting context only.

The chart-level interpretation should name the score bins gaining or losing mass, then link them to contribution and PSI trend. PSI indicates population shift; do not claim model degradation without performance evidence.
