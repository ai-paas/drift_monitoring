# CHART-MV-004 Guide

This chart explains a multivariate mean-vector shift using PCA projection, Hotelling T2/control evidence, and feature contributions.

Read in this order:

1. Summary card: T2/statistic, limit or p-value, and status.
2. PCA projection: baseline/current cloud position, separation, and outlying current points.
3. T2/control chart: window statistic relative to its limit and recent movement.
4. Contribution bars: variables with the largest contribution to the mean shift.
5. Notes/legend: use as supporting context only.

The chart-level interpretation should connect the projected location shift with T2 limit evidence and the largest contributing variables. Contributions indicate directions to inspect; they do not prove causal features by themselves.
