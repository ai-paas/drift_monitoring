# CHART-PROB-001 Guide

This chart explains probability distribution drift using reference/current bin probabilities, KL trend, and contribution bars.

Read in this order:

1. Summary card: KL/statistic, p-value or threshold, and status.
2. Distribution bars: reference versus current probability by bin, naming the largest increases and decreases.
3. KL trend: window-level KL movement and any threshold or recent peak.
4. Contribution bars: bins contributing most to KL.
5. Notes/legend: use as supporting context only.

The chart-level interpretation should identify the bins where current probability grew or shrank, then connect those gaps to the KL trend and contribution ranking. KL contribution identifies influential bins, not a standalone root cause.
