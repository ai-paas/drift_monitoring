# Drift Algorithm

This package will implement the drift methods defined by the drift monitoring
documents in this repository.

The implementation order is documentation first:

1. Define a common input/output contract.
2. Define method family schemas.
3. Write one design document per drift method.
4. Implement methods against the design documents.
5. Verify outputs against the measurement catalog.

Authoritative source documents:

- `../drift_methods_catalog.md`
- `../drift_measurements_catalog.csv`
- `../drift_method_variant_links.csv`
- `../drift_method_variant_measurement_summary.csv`
- `../algorithm_variants/*_algorithm_variants.md`
