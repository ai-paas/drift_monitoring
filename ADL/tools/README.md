# ADL Portable Tools

이 폴더에는 ADL 검증용 portable 도구를 둔다.

현재 설치된 도구:

- CUE CLI: `cue/cue.exe`
- TLA+ tools: `tla2tools.jar`
- Portable Java Runtime: `java/jdk-21.0.11+10-jre/bin/java.exe`

바이너리와 다운로드 파일은 용량이 크므로 Git 추적 대상에서 제외한다.

## 실행

루트 디렉터리에서 다음 명령을 실행한다.

```powershell
.\ADL\run_adl_checks.ps1
```
