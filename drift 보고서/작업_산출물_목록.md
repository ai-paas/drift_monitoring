# Drift 모니터링 산출물 목록

작성일: 2026-06-17

이 문서는 drift 모니터링 관련 산출물을 기준 문서, 웹 프로그램 입력, 생성 산출물, 참고/초안 자료로 구분해 관리하기 위한 목록표다.

## 요약

| 구분 | 수량 | 설명 |
|---|---:|---|
| drift 메소드 카탈로그 | 1개 | drift 측정 방법 자체를 확정한 기준 목록 |
| algorithm variant 문서 | 57개 | `algorithm_variants/` 아래 method별 variant 문서 |
| 메소드-변종 연결 | 176개 변종 | drift method와 variant의 연결 CSV |
| 측정값 카탈로그 | 42개 측정값 | drift 측정값의 표준 ID, 이름, 분류 |
| 메소드-변종-측정값 연결 | 485개 연결 | 각 변종이 산출하는 측정값 연결 |
| 파라미터 정리 | 176개 변종 | 각 변종별 사용 파라미터 목록 |
| 차트 정의 | 53개 chart id | 변종별로 사용할 수 있는 공통 차트 정의 |
| 차트 원본 코드 | 53개 세트 | chart id별 HTML/CSS/JS |
| 생성된 차트 이미지 | 53개 PNG | `charts/output/`의 chart id별 PNG |
| 차트 해석 문서 | 25개 | family별 해석 문서 24개와 인덱스 1개 |
| DB 설계서 | 1개 | 문서/CSV 지식베이스와 실행 결과를 RDB로 관리하기 위한 논리 설계 |
| DB 구축 스크립트 | 2개 | PostgreSQL schema와 Markdown/CSV import 스크립트 |

## 웹 프로그램 연결 기준

| 연결 단계 | 파일 | 현재 역할 |
|---|---|---|
| 웹 실행 진입점 | `charts/chart_selector_server.py` | `gallery.html` 정적 파일 제공, `/api/health`, `/api/select-chart` 제공 |
| 차트 추천 원천 문서 | `chart_docs/drift_method_variant_chart_guide.md` | 서버가 런타임에 읽어 Codex chart selector 프롬프트에 포함 |
| 차트 목록 UI | `charts/gallery.js` | 53개 chart id와 chart HTML 파일을 직접 정의 |
| 차트 설명 데이터 | `charts/description_data.js` | `chart_docs/drift_chart_interpretation_*.md`에서 생성된 갤러리 설명 데이터 |
| 탐지 방법-차트 연결 데이터 | `charts/method_data.js` | `chart_docs/drift_method_variant_chart_guide.md`에서 생성된 연결 데이터 |
| 탐지 방법 상세 설명 | `charts/method_description_data.js` | `algorithm_variants/*_algorithm_variants.md`에서 생성된 설명 데이터 |
| 데이터 생성 스크립트 | `charts/generate_description_html.py` | Markdown 원천 문서에서 `charts/descriptions/`, `description_data.js`, `method_data.js`, `method_description_data.js` 재생성 |
