# EDF 계열 차트 해석 가이드

이 문서는 CHART-EDF chart id의 이미지와 해석 방법을 정리한다.

## CHART-EDF-001: KS 검정으로 확인하는 현재 분포의 오른쪽 이동

![CHART-EDF-001](../charts/output/CHART-EDF-001.png)

### 제목

KS 검정으로 확인하는 현재 분포의 오른쪽 이동

### 차트 목적

`CHART-EDF-001`은 기준 구간(reference window)과 현재 구간(current window)의 단변량 분포를 비교하기 위한 차트다. KS Test 계열처럼 경험분포함수, ECDF, 사이의 최대 차이를 이용하는 drift 측정 방법에 사용한다.

이 차트는 두 가지 질문에 답한다.

```text
1. 두 구간의 누적분포가 어느 정도 다른가?
2. 실제 값의 분포가 어느 구간에서 이동했는가?
```

### 현재 상황 요약

현재 상황은 기준 구간의 feature 분포보다 현재 구간의 feature 값이 전반적으로 큰 쪽으로 이동한 사례다. 기준 구간은 260개 표본, 현재 구간은 230개 표본이며, 예시 데이터의 평균은 기준 약 `-0.02`에서 현재 약 `0.49`로 올라간다. ECDF 패널에서는 x≈`0.74`에서 기준 CDF가 `0.804`, 현재 CDF가 `0.587`로 벌어지며 KS 통계량 `D=0.217`이 나타난다. 근사 p-value는 `<0.001`이므로 두 구간이 같은 분포라는 가설에 반하는 신호가 강하고, 히스토그램에서도 현재 분포가 오른쪽으로 이동한 단변량 feature drift 후보로 해석한다.

### 차트 구성

왼쪽 패널은 경험 CDF 비교다.

- 파란 선은 기준 구간의 경험 CDF다.
- 붉은 선은 현재 구간의 경험 CDF다.
- 초록색 점선은 두 CDF 사이의 최대 세로 차이다.
- 이 최대 차이가 `KS 통계량`이다.

오른쪽 패널은 히스토그램 밀도 비교다.

- 파란 막대는 기준 구간의 값 분포다.
- 붉은 막대는 현재 구간의 값 분포다.
- 두 막대가 어긋나는 구간은 분포 이동이 발생한 위치를 보여준다.

상단 요약 카드에는 다음 값이 표시된다.

- `KS 통계량`: 두 경험 CDF 사이의 최대 차이
- `근사 p-value`: 같은 분포라는 귀무가설을 기각할 통계적 근거
- `표본 수`: 기준 구간과 현재 구간의 sample size

### 해석 순서

먼저 `KS 통계량`을 본다.

```text
KS 통계량이 작다
  -> 두 경험 CDF의 최대 차이가 작다.
  -> 단변량 분포 차이 신호가 약하다.

KS 통계량이 크다
  -> 두 경험 CDF 사이에 큰 간격이 있는 구간이 있다.
  -> 단변량 분포 변화 후보가 강하다.
```

그 다음 왼쪽 ECDF 패널에서 초록색 최대 차이 위치를 확인한다. 최대 차이가 발생한 x축 위치는 기준 구간과 현재 구간의 누적 비율 차이가 가장 큰 값 구간이다. 이 위치는 drift 설명 문장에서 “어느 값 범위에서 차이가 컸는가”를 말할 때 사용한다.

그 다음 오른쪽 히스토그램을 본다. ECDF는 누적 차이를 보여주지만, 실제 분포가 오른쪽으로 이동했는지, 분산이 넓어졌는지, 특정 tail이 두꺼워졌는지는 히스토그램이 더 직관적이다.

마지막으로 p-value와 표본 수를 함께 확인한다.

```text
p-value가 작고 KS 통계량도 크다
  -> 분포 변화 신호가 비교적 강하다.

p-value는 작지만 KS 통계량이 작다
  -> sample size가 커서 작은 차이도 유의하게 나온 것일 수 있다.

p-value가 크지만 KS 통계량이 커 보인다
  -> sample size가 작아 검정력이 부족할 수 있다.
```

### Drift 후보 판단 기준

KS 통계량이 관리 기준을 넘고 p-value가 작으며, ECDF 최대 차이 위치와 히스토그램 이동 구간이 같은 방향으로 설명될 때 단변량 feature drift 후보로 해석한다. 표본 수가 매우 크거나 다중 검정 상황이면 효과 크기와 보정 결과를 함께 확인한다.

### 이 예시 차트의 해석

이 예시에서는 KS 통계량이 `0.217`이고 근사 p-value는 `<0.001`이다. 따라서 기준 구간과 현재 구간이 같은 분포라는 가설을 기각할 근거가 강하다.

패널별로는 다음처럼 읽는다.

```text
경험 CDF 비교
  - 파란 선은 기준 구간 260개 표본의 ECDF, 붉은 선은 현재 구간 230개 표본의 ECDF다.
  - x≈0.74에서 기준 CDF는 0.804, 현재 CDF는 0.587로 차이가 가장 크다.
  - 같은 값 0.74 이하에 포함되는 비율이 현재 구간에서 더 낮으므로, 현재 값들이 기준보다 오른쪽으로 이동했다고 읽는다.

분포 비교
  - 기준 구간 평균은 약 -0.02, 현재 구간 평균은 약 0.49다.
  - 히스토그램에서도 현재 구간의 붉은 막대가 기준 구간보다 큰 값 쪽으로 더 많이 분포한다.
  - ECDF의 최대 차이 방향과 히스토그램의 위치 이동이 같은 방향인지 확인한다.
```

왼쪽 ECDF 패널을 보면 현재 구간의 붉은 CDF가 기준 구간의 파란 CDF보다 오른쪽으로 밀려 있다. 이는 현재 구간의 값이 기준 구간보다 전반적으로 커졌을 가능성을 보여준다.

오른쪽 히스토그램에서도 붉은 분포가 파란 분포보다 오른쪽 구간에 더 많이 분포한다. 따라서 이 예시는 단순한 p-value 신호가 아니라, 분포 위치 이동이 시각적으로도 확인되는 사례다.

보고서 문장 예시는 다음과 같다.

```text
기준 구간과 현재 구간의 단변량 feature 분포를 KS Test 관점에서 비교한 결과,
KS 통계량은 0.217, 근사 p-value는 0.001 미만으로 나타났다.
ECDF와 히스토그램을 함께 보면 현재 구간의 분포가 기준 구간보다 오른쪽으로 이동한 패턴이 관측된다.
이는 해당 feature의 covariate shift 후보 신호로 해석할 수 있다.
```

### 금지해야 할 해석

이 차트만으로 다음을 단정하지 않는다.

```text
금지 1
  - 모델 성능이 저하되었다.

금지 2
  - concept drift가 발생했다.

금지 3
  - 분포 변화의 원인이 특정되었다.

금지 4
  - 모든 feature 또는 전체 embedding distribution이 변했다.
```

KS Test는 단변량 분포 비교다. label 또는 ground truth 없이 성능 저하를 확정할 수 없고, 단일 feature 결과만으로 전체 데이터 구조 변화를 확정할 수도 없다.

### 추가 확인 항목

이 차트에서 drift 후보가 보이면 다음을 추가 확인한다.

- 같은 기간의 data quality, missing rate, schema 변경 여부
- 해당 feature의 단위, scaling, clipping, outlier 처리 변경 여부
- 여러 feature를 동시에 검정했다면 다중 검정 보정 여부
- 기간별 histogram 또는 ECDF trend
- label 확보 후 성능 지표 변화
- 다른 detector, 예: Wasserstein Distance, PSI, MMD, 와의 합의 여부

### 적합한 사용 대상

이 chart는 다음 method variant에 적합하다.

- `KS Test / ONE_SAMPLE_KS_KNOWN_CDF`
- `KS Test / TWO_SAMPLE_KS_TWO_SIDED`
- `KS Test / TWO_SAMPLE_KS_ONE_SIDED_GREATER`
- `KS Test / TWO_SAMPLE_KS_ONE_SIDED_LESS`
- `KS Test / TWO_SAMPLE_KS_EXACT_PVALUE`
- `KS Test / TWO_SAMPLE_KS_ASYMPTOTIC_PVALUE`
- `KS Test / KS_WITH_TIES_OR_DISCRETE_CAUTION`
- `KS Test / LILLIEFORS_RELATED_ONE_SAMPLE`
- `KS Test / HIGHER_ORDER_KS`
- `KS Test / TWO_SAMPLE_KS_APPROX_QUANTILE`

다만 one-sided 변종에서는 차트에 방향성 가설을 명시해야 한다. approximate 변종에서는 approximation error, quantile error, summary method를 caption 또는 보조 패널에 추가해야 한다.

## CHART-EDF-002: 상위 꼬리 극단값 확대로 보는 분포 변화

![CHART-EDF-002](../charts/output/CHART-EDF-002.png)

### 제목

상위 꼬리 극단값 확대로 보는 분포 변화

### 차트 목적

`CHART-EDF-002`는 기준 구간과 현재 구간의 분포 차이 중 특히 양쪽 tail 차이를 확인하기 위한 차트다. Anderson-Darling Test처럼 분포 중심부보다 tail 차이에 더 민감한 검정 계열에 적합하다.

이 차트는 다음 질문에 답한다.

```text
1. 중심부 분포는 비슷해 보여도 tail 구간이 달라졌는가?
2. 현재 구간에서 극단값 또는 위험 구간의 값이 더 자주 나타나는가?
3. 분위수 관점에서 현재 구간의 하위/상위 tail이 기준 구간보다 멀어졌는가?
```

### 현재 상황 요약

현재 상황은 분포 중심부의 차이보다 상위 tail에서 현재 구간의 극단값이 더 커진 사례다. 기준/현재 구간은 각각 260개 표본이고, 현재 구간은 일부 관측치에 큰 변동이 섞여 있다. 요약 카드의 AD 통계량은 `2.84`, 근사 p-value는 `0.012`, tail 차이는 `0.50`이다. QQ 비교에서 상위 98% 분위수는 기준 `2.38`에서 현재 `3.10`으로, 상위 99% 분위수는 기준 `2.60`에서 현재 `3.61`로 커진다. 따라서 이 예시는 전체 평균 이동보다 위험 구간 또는 극단값 영역의 확대를 우선 의심해야 하는 tail drift 후보로 해석한다.

### 차트 구성

왼쪽 패널은 tail 강조 경험 CDF 비교다.

- 파란 선은 기준 구간의 경험 CDF다.
- 붉은 선은 현재 구간의 경험 CDF다.
- 보라색 음영은 하위 tail과 상위 tail 강조 구간이다.
- 두 선이 tail 구간에서 벌어지면 극단값 쪽 분포 차이가 있다는 뜻이다.

오른쪽 패널은 QQ 비교다.

- x축은 기준 구간의 분위수다.
- y축은 현재 구간의 분위수다.
- 점선은 기준 분위수와 현재 분위수가 같은 경우의 기준선이다.
- 점이 점선에서 멀어질수록 해당 분위수에서 기준 구간과 현재 구간의 값 차이가 크다.
- tail 쪽 점이 크게 벗어나면 중심부보다 tail 차이가 큰 것이다.

상단 요약 카드에는 다음 값이 표시된다.

- `AD 통계량`: Anderson-Darling 계열 tail-sensitive 검정량
- `근사 p-value`: 같은 분포라는 귀무가설을 기각할 통계적 근거
- `Tail 차이`: 하위/상위 tail 분위수 차이를 요약한 보조 지표

### 해석 순서

먼저 QQ 비교를 본다. QQ plot에서 점들이 대각선에 가까우면 기준 구간과 현재 구간의 분위수 구조가 비슷하다. 상위 tail 또는 하위 tail의 점들이 대각선에서 멀어지면, 극단값 구간에서 분포 차이가 있다는 뜻이다.

다음으로 왼쪽 CDF 패널의 음영 구간을 확인한다. 중심부에서는 두 CDF가 비슷해도 tail 구간에서 차이가 벌어질 수 있다. 이런 경우 KS Test에서는 차이가 작아 보일 수 있지만 Anderson-Darling 계열에서는 더 중요한 신호가 될 수 있다.

마지막으로 AD 통계량과 p-value를 함께 본다.

```text
AD 통계량이 크고 p-value가 작다
  -> tail을 포함한 분포 차이 신호가 강하다.

중심부는 비슷하지만 QQ tail 점이 대각선에서 벗어난다
  -> 극단값 또는 위험 구간의 drift 후보로 해석한다.

tail 차이가 크지만 표본 수가 작다
  -> outlier 몇 개의 영향인지 추가 확인한다.
```

### Drift 후보 판단 기준

AD 통계량이 관리 기준을 넘고 QQ plot의 상위 또는 하위 tail 점들이 기준선에서 일관되게 벗어나면 tail drift 후보로 해석한다. 단, outlier 처리 정책과 tail sample size를 먼저 확인한다.

### 이 예시 차트의 해석

이 예시에서는 AD 통계량이 `2.84`, 근사 p-value가 `0.012`로 표시되어 있다. 이는 기준 구간과 현재 구간의 분포가 같다는 가설을 기각할 근거가 있음을 뜻한다.

패널별로는 다음처럼 읽는다.

```text
Tail 가중 CDF 비교
  - 보라색 음영은 기준 구간의 하위 5%와 상위 5% tail 영역이다.
  - 중심부에서는 두 ECDF가 크게 벌어지지 않아도, tail 영역에서 붉은 현재 CDF의 움직임을 따로 확인한다.
  - tail 차이가 0.50으로 표시되므로 중심부 평균보다 극단값 영역 차이를 먼저 해석한다.

QQ 비교
  - 대각선은 기준 분위수와 현재 분위수가 같은 경우다.
  - 상위 98% 분위수는 기준 2.38, 현재 3.10이고 상위 99% 분위수는 기준 2.60, 현재 3.61이다.
  - 상위 tail 점들이 대각선 위쪽으로 벗어나므로 현재 구간의 큰 값 극단치가 기준보다 커졌다고 읽는다.
```

왼쪽 CDF 패널에서는 중심부의 차이는 아주 크지 않지만, tail 강조 구간에서 현재 구간의 분포가 기준 구간과 다르게 움직이는 모습이 보인다. 오른쪽 QQ 비교에서는 특히 높은 분위수의 점들이 대각선 위쪽으로 벗어난다. 이는 현재 구간의 상위 tail 값이 기준 구간보다 커졌다는 뜻이다.

보고서 문장 예시는 다음과 같다.

```text
기준 구간과 현재 구간을 Anderson-Darling 계열 관점에서 비교한 결과,
AD 통계량은 2.84, 근사 p-value는 0.012로 나타났다.
QQ 비교에서 상위 분위수의 현재 값이 기준 분위수보다 크게 나타나므로,
현재 구간에서 상위 tail 또는 극단값 영역의 분포 변화 후보가 관측된다.
```

### 금지해야 할 해석

이 차트만으로 다음을 단정하지 않는다.

```text
금지 1
  - 극단값 증가가 곧바로 모델 성능 저하를 의미한다.

금지 2
  - tail 변화의 원인이 outlier, 데이터 품질, 실제 population 변화 중 무엇인지 확정한다.

금지 3
  - tail 차이만으로 전체 분포가 모든 구간에서 변했다고 말한다.

금지 4
  - label 없이 concept drift가 발생했다고 확정한다.
```

## CHART-EDF-003: 중간값 이후 누적되는 CDF 차이로 보는 분포 변화

![CHART-EDF-003](../charts/output/CHART-EDF-003.png)

### 제목

중간값 이후 누적되는 CDF 차이로 보는 분포 변화

### 차트 목적

`CHART-EDF-003`은 기준 구간과 현재 구간의 경험 CDF 차이가 전체 값 범위에서 얼마나 누적되는지 확인하기 위한 차트다. Cramer-von Mises Test 계열처럼 특정 지점의 최대 차이보다 전체 CDF 차이의 제곱 면적을 사용하는 drift 측정 방법에 적합하다.

이 차트는 다음 질문에 답한다.

```text
1. 두 경험 CDF가 전체 구간에서 지속적으로 벌어지는가?
2. drift 신호가 특정 한 지점의 최대 차이인지, 여러 구간에 걸쳐 누적된 차이인지?
3. 어느 값 범위에서 제곱 CDF 차이의 기여가 크게 쌓이는가?
```

### 현재 상황 요약

현재 상황은 기준 구간과 현재 구간의 차이가 한 지점의 큰 최대 편차로만 나타나는 것이 아니라, 중간값 이후 여러 값 범위에서 반복적으로 누적되는 사례다. 기준/현재 구간은 각각 280개 표본이고, 현재 구간은 일부 값이 오른쪽으로 이동한 mixture 형태다. 요약 카드의 CvM 통계량은 `1.89`, 근사 p-value는 `0.018`, 누적 면적은 `0.014`다. x≈`0.07`에서 기준 CDF가 `0.550`, 현재 CDF가 `0.436`으로 가장 큰 제곱 차이가 나타나고, 누적 제곱 차이 곡선은 이 구간 이후 빠르게 쌓인다. 따라서 이 예시는 단일 spike보다 전체 분포 형태의 누적 변화 후보로 해석한다.

### 차트 구성

왼쪽 패널은 경험 CDF 비교다.

- 파란 선은 기준 구간의 경험 CDF다.
- 붉은 선은 현재 구간의 경험 CDF다.
- 노란 점선은 두 CDF 사이의 세로 차이를 예시로 표시한다.
- 여러 값 구간에서 작은 CDF 차이가 반복되면 CvM 통계량에 누적 기여한다.

오른쪽 패널은 누적 제곱 CDF 차이다.

- x축은 특성값이다.
- y축은 `기준 CDF - 현재 CDF` 차이를 제곱한 뒤 왼쪽부터 누적한 값이다.
- 곡선의 기울기가 커지는 구간은 drift 근거가 많이 쌓이는 값 범위다.
- 노란 음영은 이 예시에서 제곱 차이가 큰 대표 구간을 강조한다.

상단 요약 카드에는 다음 값이 표시된다.

- `CvM 통계량`: 전체 CDF 차이의 제곱 누적량을 표본 규모로 보정한 요약값
- `근사 p-value`: 같은 분포라는 귀무가설을 기각할 통계적 근거
- `누적 면적`: 표본 보정 전 CDF 제곱 차이 면적

### 해석 순서

먼저 왼쪽 ECDF 패널에서 두 CDF가 특정 한 지점에서만 크게 벌어지는지, 아니면 넓은 구간에서 지속적으로 차이를 보이는지 확인한다. Cramer-von Mises 계열은 KS Test처럼 최대 차이 한 지점만 보지 않고 전체 구간의 차이를 함께 반영한다.

그 다음 오른쪽 누적 제곱 차이 패널을 본다. 곡선이 완만하면 해당 구간에서는 CDF 차이가 작게 누적되는 것이다. 곡선이 빠르게 상승하면 그 값 범위에서 두 CDF 차이가 반복적으로 커졌다는 뜻이다.

마지막으로 CvM 통계량과 p-value를 함께 확인한다.

```text
CvM 통계량이 크고 p-value가 작다
  -> 전체 분포 형태 차이 신호가 강하다.

KS 통계량은 크지 않지만 CvM 통계량이 커진다
  -> 한 지점의 급격한 차이보다 넓은 구간의 누적 차이가 원인일 수 있다.

누적 곡선이 특정 구간에서만 급상승한다
  -> 해당 값 범위가 drift 설명의 핵심 후보 구간이다.
```

### Drift 후보 판단 기준

CvM 통계량이 관리 기준을 넘고 누적 제곱 CDF 차이 곡선이 특정 값 범위에서 뚜렷하게 상승하면 전반적 분포 형태 drift 후보로 해석한다.

### 이 예시 차트의 해석

이 예시에서는 CvM 통계량이 `1.89`, 근사 p-value가 `0.018`로 표시되어 있다. 이는 기준 구간과 현재 구간의 분포가 같다는 가설을 기각할 근거가 있음을 뜻한다.

패널별로는 다음처럼 읽는다.

```text
경험 CDF 비교
  - 파란 선은 기준 구간 280개 표본의 ECDF, 붉은 선은 현재 구간 280개 표본의 ECDF다.
  - x≈0.07에서 기준 CDF는 0.550, 현재 CDF는 0.436으로 차이가 가장 크게 제곱 기여한다.
  - 현재 중앙값은 약 0.18이고 기준 중앙값은 약 -0.07이므로, 현재 분포가 중간 구간에서 오른쪽으로 이동한 패턴을 함께 본다.

누적 제곱 CDF 차이
  - y축은 CDF 차이를 제곱한 뒤 왼쪽부터 누적한 값이다.
  - 최종 누적 면적은 0.014이고, x≈0.10 부근까지 전체 누적량의 약 72%가 쌓인다.
  - 곡선이 빠르게 올라가는 구간이 drift 설명의 핵심 값 범위다.
```

왼쪽 ECDF 비교에서는 두 CDF 사이의 차이가 한 지점에서만 나타나기보다 중간값 이후 여러 구간에서 반복적으로 벌어진다. 오른쪽 누적 제곱 차이 패널에서도 특정 값 범위 이후 곡선이 더 빠르게 상승한다. 따라서 이 예시는 단일 최대 편차보다 전체 분포 형태의 누적 변화가 중요한 사례로 해석할 수 있다.

보고서 문장 예시는 다음과 같다.

```text
기준 구간과 현재 구간을 Cramer-von Mises 계열 관점에서 비교한 결과,
CvM 통계량은 1.89, 근사 p-value는 0.018로 나타났다.
ECDF 차이가 특정 한 지점에만 집중되지 않고 중간값 이후 여러 구간에서 누적되며,
누적 제곱 CDF 차이 곡선도 해당 구간에서 빠르게 상승한다.
이는 전반적인 단변량 분포 형태 변화 후보로 해석할 수 있다.
```

## CHART-EDF-004: 원형 데이터의 피크 각도 이동과 CDF 편차

![CHART-EDF-004](../charts/output/CHART-EDF-004.png)

### 제목

원형 데이터의 피크 각도 이동과 CDF 편차

### 차트 목적

`CHART-EDF-004`는 기준 구간과 현재 구간의 경험 CDF 차이를 양방향으로 분해해 확인하기 위한 차트다. Kuiper's Test처럼 CDF의 양의 최대 편차 `D+`와 음의 최대 편차 `D-`를 더해 사용하는 검정에 적합하다.

이 차트는 다음 질문에 답한다.

```text
1. 현재 CDF가 기준 CDF보다 위로 벌어진 구간과 아래로 벌어진 구간이 각각 어디인가?
2. 양방향 편차를 합친 Kuiper 통계량이 drift 신호를 만들고 있는가?
3. 각도, 시간대, 계절성처럼 시작점이 임의적인 circular data에서 분포 peak가 이동했는가?
```

### 현재 상황 요약

현재 상황은 각도형 또는 순환형 feature에서 기준 구간의 peak 위치가 현재 구간에서 다른 각도대로 이동한 사례다. Kuiper V는 `0.377`, 근사 p-value는 `0.009`로 표시된다. 양의 편차 D+는 `0.012`로 작지만, 음의 편차 D-는 `0.365`로 크고 약 `49.5°`에서 발생한다. 원형 히스토그램에서도 기준 구간은 `20~40°` 구간에 가장 많이 몰려 있지만 현재 구간은 `40~80°`와 `240~260°` 쪽 비중이 커진다. 따라서 이 예시는 일반 선형 feature의 평균 이동보다 circular data의 peak 각도 이동 후보로 해석한다.

### 차트 구성

왼쪽 패널은 ECDF 양/음 편차다.

- y축은 `현재 CDF - 기준 CDF`다.
- 0보다 큰 영역은 현재 CDF가 기준 CDF보다 위에 있는 구간이다.
- 0보다 작은 영역은 현재 CDF가 기준 CDF보다 아래에 있는 구간이다.
- `D+`는 양의 최대 편차, `D-`는 음의 최대 편차의 절댓값이다.
- Kuiper 통계량 `V`는 `D+ + D-`로 계산한다.

오른쪽 패널은 원형 히스토그램이다.

- 안쪽 파란 막대는 기준 구간의 각도형 분포다.
- 바깥쪽 붉은 막대는 현재 구간의 각도형 분포다.
- peak 위치가 회전하거나 특정 방향의 빈도가 바뀌면 circular data drift 후보로 본다.
- `shift` 표시는 기준 대비 현재 비중 차이가 큰 각도 구간을 강조한다.

상단 요약 카드에는 다음 값이 표시된다.

- `Kuiper V`: 양의 최대 편차와 음의 최대 편차를 합친 통계량
- `D+ / D-`: 위쪽 편차와 아래쪽 편차의 크기
- `근사 p-value`: 같은 분포라는 귀무가설을 기각할 통계적 근거

### 해석 순서

먼저 왼쪽 편차 패널에서 `D+`와 `D-`가 어디에서 발생하는지 확인한다. 한쪽 편차만 크면 단방향 위치 이동에 가깝고, 양쪽 편차가 모두 크면 분포의 위치와 형태가 함께 바뀌었을 가능성이 있다.

그 다음 Kuiper V와 p-value를 함께 본다.

```text
Kuiper V가 크고 p-value가 작다
  -> 양방향 CDF 편차를 합친 분포 차이 신호가 강하다.

D+만 크다
  -> 현재 CDF가 기준보다 빠르게 누적되는 구간이 핵심이다.

D-만 크다
  -> 현재 CDF가 기준보다 늦게 누적되는 구간이 핵심이다.

D+와 D-가 모두 크다
  -> 분포 peak 이동, 형태 변화, circular 위치 이동을 함께 의심한다.
```

마지막으로 오른쪽 원형 히스토그램을 확인한다. circular data에서는 0도와 360도가 이어져 있으므로, 일반 ECDF만 보면 시작점 선택에 따라 해석이 흔들릴 수 있다. 원형 히스토그램은 peak가 어느 방향으로 이동했는지 보완적으로 보여준다.

### Drift 후보 판단 기준

Kuiper V가 관리 기준을 넘고 D+ 또는 D-가 명확하면 위치 이동 또는 circular distribution drift 후보로 해석한다. circular data에서는 시작점과 wrap-around 처리를 함께 확인한다.

### 이 예시 차트의 해석

이 예시에서는 Kuiper V가 `0.377`, 근사 p-value가 `0.009`로 표시되어 있다. 이는 기준 구간과 현재 구간의 분포가 같다는 가설을 기각할 근거가 있음을 뜻한다.

패널별로는 다음처럼 읽는다.

```text
ECDF 양/음 편차
  - y축은 현재 CDF - 기준 CDF다.
  - D+는 0.012로 작고, D-는 0.365로 크며 약 49.5°에서 발생한다.
  - 현재 CDF가 이 구간에서 기준보다 늦게 누적되므로 현재 값들이 더 뒤쪽 각도 구간으로 이동했다고 읽는다.

원형 히스토그램
  - 기준 구간의 가장 큰 peak는 20~40° 구간이며 비중은 약 28.8%다.
  - 현재 구간은 40~60°와 60~80° 구간이 커지고, 240~260° 구간도 약 18.8%로 커진다.
  - 0°와 360°가 이어지는 데이터이므로 선형 histogram만 보지 말고 원형 위치 이동으로 해석한다.
```

왼쪽 편차 패널에서는 음의 편차가 지배적으로 나타난다. 이는 현재 구간의 CDF가 일부 각도 구간에서 기준보다 늦게 누적된다는 뜻이다. 오른쪽 원형 히스토그램에서도 기준 구간과 현재 구간의 peak 각도가 서로 어긋나므로, circular distribution의 위치 이동 후보로 볼 수 있다.

보고서 문장 예시는 다음과 같다.

```text
기준 구간과 현재 구간을 Kuiper Test 관점에서 비교한 결과,
Kuiper V는 0.377, 근사 p-value는 0.009로 나타났다.
ECDF 편차 패널에서 D+와 D-가 모두 확인되며,
원형 히스토그램에서도 현재 구간의 peak 각도가 기준 구간 대비 이동한 패턴이 관측된다.
이는 각도형 또는 주기형 feature의 분포 이동 후보로 해석할 수 있다.
```

### 금지해야 할 해석

이 차트만으로 다음을 단정하지 않는다.

```text
금지 1
  - circular feature 변화가 곧바로 모델 성능 저하를 의미한다.

금지 2
  - peak 이동의 원인이 계절성, 수집 시간대, 사용자 행동 변화 중 무엇인지 확정한다.

금지 3
  - 시작점 선택의 영향을 검토하지 않고 일반 단변량 분포처럼만 해석한다.

금지 4
  - p-value 하나만으로 운영 알람 또는 재학습을 확정한다.
```

### 추가 확인 항목

Kuiper 관점에서 분포 차이가 보이면 다음을 추가 확인한다.

- 해당 feature가 각도, 시간대, 요일, 계절성처럼 circular 구조를 갖는지
- 0도와 360도 또는 하루 시작점 같은 wrap-around 경계 처리 방식
- peak가 이동한 구간의 segment, 시간대, source system 변화
- 같은 feature의 KS Test, Cramer-von Mises Test, Wasserstein Distance 결과
- sample size와 반복 검정에 따른 다중 검정 보정 여부
- label 확보 후 성능 지표, calibration, error rate 변화
