# 문서-웹 프로그램 연결 정리

작성일: 2026-06-17

이 문서는 drift 보고서 폴더의 문서가 웹 프로그램에서 어떻게 쓰이는지, 그리고 정리 대상이 무엇인지 판단하기 위한 기준 문서다.

## 현재 웹 프로그램 구조

웹 프로그램은 `charts/chart_selector_server.py`로 실행되는 로컬 갤러리다.

```text
python charts\chart_selector_server.py
-> http://127.0.0.1:8765/gallery.html
```

갤러리는 다음 세 가지 정보를 보여준다.

1. chart id별 HTML 차트
2. chart id별 해석 설명
3. chart id와 drift 탐지 방법/variant의 연결

또한 `/api/select-chart`는 사용자 자연어 요청을 받아 `chart_docs/drift_method_variant_chart_guide.md`를 기준으로 적절한 chart id를 추천한다.

## 런타임에 직접 쓰이는 파일

| 파일 | 사용 위치 | 설명 |
|---|---|---|
| `charts/gallery.html` | 브라우저 진입점 | 차트 갤러리 UI |
| `charts/gallery.css` | 브라우저 | 갤러리 UI 스타일 |
| `charts/gallery.js` | 브라우저 | 53개 chart id 목록, 검색, 탭, 설명/방법 패널 제어 |
| `charts/chart_*.html` | 브라우저 iframe | chart id별 차트 화면 |
| `charts/chart_*.css` | 각 chart HTML | chart id별 스타일 |
| `charts/chart_*.js` | 각 chart HTML | chart id별 렌더링 데이터와 로직 |
| `charts/description_data.js` | `gallery.html` | chart id별 설명 HTML 데이터 |
| `charts/method_data.js` | `gallery.html` | chart id별 연결 method 목록 |
| `charts/method_description_data.js` | `gallery.html` | method/variant별 상세 설명 HTML |
| `chart_docs/drift_method_variant_chart_guide.md` | `chart_selector_server.py` | Codex chart selector의 판단 기준 |

## 생성 데이터의 원천 문서

`charts/generate_description_html.py`는 Markdown 원천 문서를 읽어 갤러리용 데이터를 생성한다.

| 생성 파일 | 원천 문서 |
|---|---|
| `charts/descriptions/*_desc.html` | `chart_docs/drift_chart_interpretation_*.md` |
| `charts/description_data.js` | `chart_docs/drift_chart_interpretation_*.md` |
| `charts/method_data.js` | `chart_docs/drift_method_variant_chart_guide.md` |
| `charts/method_description_data.js` | `algorithm_variants/*_algorithm_variants.md` |

따라서 위 원천 문서는 웹에서 직접 열리지 않더라도, 갤러리 데이터를 재생성하는 데 필요한 문서다.

## 웹 미연결이지만 유지 가치가 있는 문서

| 파일 | 유지 이유 |
|---|---|
| `drift_methods_catalog.md` | method 체계의 기준 문서 |
| `drift_measurements_interpretation_guide.md` | 측정값 해석 기준 |
| `drift_measurement_method_selection_guide.md` | 같은 측정값을 여러 method가 산출할 때 선택 기준 |
| `drift_method_parameter_guide.md` | 추천과 설정 설명에 필요한 파라미터 기준 |
| `drift_method_variant_links.csv` | method-variant 구조화 데이터 |
| `drift_measurements_catalog.csv` | 측정값 구조화 데이터 |
| `drift_method_variant_measurement_links.csv` | variant-measurement 구조화 데이터 |
| `drift_method_variant_measurement_summary.csv` | variant별 측정값 요약 |
| `drift_measurement_to_methods.csv` | measurement 기준 역인덱스 |
| `drift_method_variant_parameters.csv` | variant별 파라미터 구조화 데이터 |

이 문서와 CSV는 현재 갤러리 UI에 직접 연결되어 있지는 않지만, LLM 추천/보고서 자동화/검색 인덱스 작업의 원천 데이터로 볼 수 있다.

## 정리 원칙

1. `charts/generate_description_html.py`의 원천 문서는 삭제하지 않는다.
2. `chart_docs/drift_method_variant_chart_guide.md`는 서버 런타임 추천 기준이므로 삭제하지 않는다.
3. 웹에서 직접 참조하지 않아도 구조화 CSV와 해석 가이드는 보고서/LLM 추천 원천이면 유지한다.
4. 백업 디렉터리, 로컬 로그, Chrome 프로필처럼 재생성 가능하거나 현재 참조되지 않는 파일은 archive 또는 Git 제외 대상으로 분리한다.
5. 문서를 이동하면 `작업_산출물_목록.md`와 관련 링크를 함께 갱신한다.
