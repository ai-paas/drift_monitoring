CHART-EDF-002

CHART-EDF-002 해석

차트 목적

CHART-EDF-002는 기준 구간과 현재 구간의 분포 차이 중 특히 양쪽 tail 차이를 확인하기 위한 차트다. Anderson-Darling Test처럼 분포 중심부보다 tail 차이에 더 민감한 검정 계열에 적합하다.

이 차트는 다음 질문에 답한다.

1. 중심부 분포는 비슷해 보여도 tail 구간이 달라졌는가?
2. 현재 구간에서 극단값 또는 위험 구간의 값이 더 자주 나타나는가?
3. 분위수 관점에서 현재 구간의 하위/상위 tail이 기준 구간보다 멀어졌는가?

차트 구성

왼쪽 패널은 tail 강조 경험 CDF 비교다.

  • 파란 선은 기준 구간의 경험 CDF다.
  • 붉은 선은 현재 구간의 경험 CDF다.
  • 보라색 음영은 하위 tail과 상위 tail 강조 구간이다.
  • 두 선이 tail 구간에서 벌어지면 극단값 쪽 분포 차이가 있다는 뜻이다.

오른쪽 패널은 QQ 비교다.

  • x축은 기준 구간의 분위수다.
  • y축은 현재 구간의 분위수다.
  • 점선은 기준 분위수와 현재 분위수가 같은 경우의 기준선이다.
  • 점이 점선에서 멀어질수록 해당 분위수에서 기준 구간과 현재 구간의 값 차이가 크다.
  • tail 쪽 점이 크게 벗어나면 중심부보다 tail 차이가 큰 것이다.

상단 요약 카드에는 다음 값이 표시된다.

  • AD 통계량: Anderson-Darling 계열 tail-sensitive 검정량
  • 근사 p-value: 같은 분포라는 귀무가설을 기각할 통계적 근거
  • Tail 차이: 하위/상위 tail 분위수 차이를 요약한 보조 지표

해석 순서

먼저 QQ 비교를 본다. QQ plot에서 점들이 대각선에 가까우면 기준 구간과 현재 구간의 분위수 구조가 비슷하다. 상위 tail 또는 하위 tail의 점들이 대각선에서 멀어지면, 극단값 구간에서 분포 차이가 있다는 뜻이다.

다음으로 왼쪽 CDF 패널의 음영 구간을 확인한다. 중심부에서는 두 CDF가 비슷해도 tail 구간에서 차이가 벌어질 수 있다. 이런 경우 KS Test에서는 차이가 작아 보일 수 있지만 Anderson-Darling 계열에서는 더 중요한 신호가 될 수 있다.

마지막으로 AD 통계량과 p-value를 함께 본다.

AD 통계량이 크고 p-value가 작다
  -> tail을 포함한 분포 차이 신호가 강하다.

중심부는 비슷하지만 QQ tail 점이 대각선에서 벗어난다
  -> 극단값 또는 위험 구간의 drift 후보로 해석한다.

tail 차이가 크지만 표본 수가 작다
  -> outlier 몇 개의 영향인지 추가 확인한다.

Drift 후보 판단 기준

AD 통계량이 관리 기준을 넘고 QQ plot의 상위 또는 하위 tail 점들이 기준선에서 일관되게 벗어나면 tail drift 후보로 해석한다. 단, outlier 처리 정책과 tail sample size를 먼저 확인한다.

이 예시 차트의 해석

이 예시에서는 AD 통계량이 2.84, 근사 p-value가 0.012로 표시되어 있다. 이는 기준 구간과 현재 구간의 분포가 같다는 가설을 기각할 근거가 있음을 뜻한다.

왼쪽 CDF 패널에서는 중심부의 차이는 아주 크지 않지만, tail 강조 구간에서 현재 구간의 분포가 기준 구간과 다르게 움직이는 모습이 보인다. 오른쪽 QQ 비교에서는 특히 높은 분위수의 점들이 대각선 위쪽으로 벗어난다. 이는 현재 구간의 상위 tail 값이 기준 구간보다 커졌다는 뜻이다.

보고서 문장 예시는 다음과 같다.

기준 구간과 현재 구간을 Anderson-Darling 계열 관점에서 비교한 결과,
AD 통계량은 2.84, 근사 p-value는 0.012로 나타났다.
QQ 비교에서 상위 분위수의 현재 값이 기준 분위수보다 크게 나타나므로,
현재 구간에서 상위 tail 또는 극단값 영역의 분포 변화 후보가 관측된다.

금지해야 할 해석

이 차트만으로 다음을 단정하지 않는다.

금지 1
  - 극단값 증가가 곧바로 모델 성능 저하를 의미한다.

금지 2
  - tail 변화의 원인이 outlier, 데이터 품질, 실제 population 변화 중 무엇인지 확정한다.

금지 3
  - tail 차이만으로 전체 분포가 모든 구간에서 변했다고 말한다.

금지 4
  - label 없이 concept drift가 발생했다고 확정한다.

추가 확인 항목

Tail 차이가 보이면 다음을 추가 확인한다.

  • 극단값이 실제 관측값인지, 수집 오류 또는 clipping 변경 때문인지
  • outlier 처리 정책, winsorization, scaling 변경 여부
  • tail 구간 sample size와 영향도
  • tail sample의 segment, 시간대, 데이터 소스
  • tail 변화가 loss, error rate, calibration error 같은 성능 지표와 연결되는지
  • KS, Wasserstein, quantile drift, anomaly score와의 합의 여부

적합한 사용 대상

이 chart는 다음 method variant에 적합하다.

  • Anderson-Darling Test / ONE_SAMPLE_ANDERSON_DARLING
  • Anderson-Darling Test / TWO_SAMPLE_ANDERSON_DARLING
  • Anderson-Darling Test / K_SAMPLE_ANDERSON_DARLING
  • Anderson-Darling Test / TAIL_SENSITIVE_AD

또한 tail 차이가 중요한 경우에는 KS Test 결과를 보완하는 보조 차트로도 사용할 수 있다.
