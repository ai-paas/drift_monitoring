CHART-STREAM-001

CHART-STREAM-001 해석

차트 목적

이 chart는 ADWIN이 stream에서 drift alarm을 발생시킨 시점과 그 전후 평균 변화, adaptive window 변화를 함께 설명한다.

ADWIN은 고정 window가 아니라 데이터 흐름에 따라 window를 유지하다가, window 내부를 둘로 나누었을 때 두 sub-window의 평균 차이가 통계적으로 커지면 오래된 구간을 버리고 alarm을 발생시킨다. 따라서 이 chart는 stream metric이 언제 다른 수준으로 바뀌었는지와 detector가 window를 어떻게 조정했는지 보여준다.

이 차트는 다음 질문에 답한다.

1. stream metric이 어느 시점부터 다른 수준으로 이동했는가?
2. ADWIN alarm 직후 adaptive window width가 줄었는가?
3. alarm 전후 평균 차이가 운영 기준보다 충분히 큰가?

차트 구성

이 chart는 세 영역으로 구성된다.

좌측
  - stream metric line
  - rolling mean line
  - ADWIN alarm marker

우측 상단
  - adaptive window width trend
  - alarm 시점의 window 축소

우측 하단
  - alarm 이전 window 평균
  - alarm 이후 window 평균
  - before/after 평균 차이

상단 요약 영역에는 alarm index, mean delta, p-value를 표시한다.

해석 순서

먼저 좌측 stream line에서 alarm 전후로 값의 수준이 실제로 달라졌는지 확인한다.

alarm 이후 값이 이전 수준으로 곧 돌아온다
  -> 일시적 spike 또는 noise 가능성을 확인한다.

alarm 이후 새 평균 수준에서 안정된다
  -> stream drift 후보로 해석한다.

alarm이 여러 번 반복된다
  -> gradual drift 또는 recurring drift 가능성을 확인한다.

그 다음 우측 상단 adaptive window width를 확인한다. ADWIN은 drift를 감지하면 오래된 데이터를 버리므로, alarm 직후 window width가 급격히 줄어드는 패턴이 자연스럽다. window가 줄지 않는데 alarm만 표시되면 detector 상태 기록이나 시각화 로직을 점검한다.

마지막으로 우측 하단 before/after mean 비교를 확인한다. 평균 차이가 운영 기준보다 크고 p-value가 기준보다 작으면, 단순 fluctuation보다 의미 있는 stream 변화 후보로 본다.

Drift 후보 판단 기준

ADWIN alarm이 발생했고, alarm 이후 adaptive window가 축소되며, before/after 평균 차이가 운영 기준을 넘고, 이후 stream이 새 수준으로 안정되면 stream drift 후보로 해석한다.

단, stream detector는 sample arrival order, delay, batch aggregation, metric smoothing 설정에 민감하다. alarm 시점 주변의 데이터 누락, 지연 적재, outlier burst를 함께 확인해야 한다.

이 예시 차트의 해석

이 예시에서는 alarm index가 23, mean delta가 +0.30, p-value가 0.009로 표시되어 있다. 좌측 stream line에서는 23번 시점 주변부터 metric이 이전 평균 수준보다 높아지고 이후 새 수준에서 안정된다.

우측 상단에서는 alarm 직후 adaptive window width가 170 수준에서 62 수준으로 줄었다가 다시 확장된다. 우측 하단에서는 alarm 전 평균 0.38과 alarm 후 평균 0.68의 차이가 0.30으로 운영 기준 0.20을 넘는다. 따라서 이 예시는 ADWIN이 stream 평균 상승을 감지한 drift 후보로 해석할 수 있다.

보고서 문장 예시는 다음과 같다.

ADWIN으로 stream metric을 모니터링한 결과,
time index 23에서 drift alarm이 발생했다.
Alarm 전 window 평균은 0.38, alarm 후 평균은 0.68로 mean delta는 +0.30이었다.
Alarm 직후 adaptive window width가 크게 축소되었고 이후 metric이 새 수준에서 안정되어,
stream 평균 상승 drift 후보로 해석할 수 있다.

금지해야 할 해석

이 차트만으로 다음을 단정하지 않는다.

금지 1
  - alarm 한 번만으로 장기 drift를 확정한다.

금지 2
  - stream metric 상승을 곧바로 모델 성능 악화로 단정한다.

금지 3
  - 데이터 지연 적재나 outlier burst 가능성을 확인하지 않는다.

금지 4
  - ADWIN window 축소를 데이터 손실로 해석한다.

ADWIN의 window 축소는 detector가 오래된 구간을 버리고 새 regime에 적응하는 동작이다. 운영 데이터 삭제나 원천 데이터 손실을 의미하지 않는다.

추가 확인 항목

ADWIN drift 후보가 나타나면 다음을 추가 확인한다.

  • alarm 시점 주변의 데이터 적재 지연, 누락, batch 크기 변화
  • metric smoothing, aggregation interval, stream ordering 변경 여부
  • alarm 전후 segment/source/time 구성 변화
  • ADWIN delta, min window length, clock 설정
  • KSWIN, Page-Hinkley, DDM 계열 detector와의 합의 여부
  • label 확보 후 성능 지표, error rate, calibration 변화

적합한 사용 대상

이 chart는 다음 method variant에 적합하다.

  • ADWIN / ADWIN_MEAN_STREAM
  • ADWIN / ADWIN_ERROR_RATE
  • ADWIN / ADWIN_DISTANCE_STREAM
