CHART-EDF-001

CHART-EDF-001 해석

차트 목적

CHART-EDF-001은 기준 구간(reference window)과 현재 구간(current window)의 단변량 분포를 비교하기 위한 차트다. KS Test 계열처럼 경험분포함수, ECDF, 사이의 최대 차이를 이용하는 drift 측정 방법에 사용한다.

이 차트는 두 가지 질문에 답한다.

1. 두 구간의 누적분포가 어느 정도 다른가?
2. 실제 값의 분포가 어느 구간에서 이동했는가?

차트 구성

왼쪽 패널은 경험 CDF 비교다.

  • 파란 선은 기준 구간의 경험 CDF다.
  • 붉은 선은 현재 구간의 경험 CDF다.
  • 초록색 점선은 두 CDF 사이의 최대 세로 차이다.
  • 이 최대 차이가 KS 통계량이다.

오른쪽 패널은 히스토그램 밀도 비교다.

  • 파란 막대는 기준 구간의 값 분포다.
  • 붉은 막대는 현재 구간의 값 분포다.
  • 두 막대가 어긋나는 구간은 분포 이동이 발생한 위치를 보여준다.

상단 요약 카드에는 다음 값이 표시된다.

  • KS 통계량: 두 경험 CDF 사이의 최대 차이
  • 근사 p-value: 같은 분포라는 귀무가설을 기각할 통계적 근거
  • 표본 수: 기준 구간과 현재 구간의 sample size

해석 순서

먼저 KS 통계량을 본다.

KS 통계량이 작다
  -> 두 경험 CDF의 최대 차이가 작다.
  -> 단변량 분포 차이 신호가 약하다.

KS 통계량이 크다
  -> 두 경험 CDF 사이에 큰 간격이 있는 구간이 있다.
  -> 단변량 분포 변화 후보가 강하다.

그 다음 왼쪽 ECDF 패널에서 초록색 최대 차이 위치를 확인한다. 최대 차이가 발생한 x축 위치는 기준 구간과 현재 구간의 누적 비율 차이가 가장 큰 값 구간이다. 이 위치는 drift 설명 문장에서 “어느 값 범위에서 차이가 컸는가”를 말할 때 사용한다.

그 다음 오른쪽 히스토그램을 본다. ECDF는 누적 차이를 보여주지만, 실제 분포가 오른쪽으로 이동했는지, 분산이 넓어졌는지, 특정 tail이 두꺼워졌는지는 히스토그램이 더 직관적이다.

마지막으로 p-value와 표본 수를 함께 확인한다.

p-value가 작고 KS 통계량도 크다
  -> 분포 변화 신호가 비교적 강하다.

p-value는 작지만 KS 통계량이 작다
  -> sample size가 커서 작은 차이도 유의하게 나온 것일 수 있다.

p-value가 크지만 KS 통계량이 커 보인다
  -> sample size가 작아 검정력이 부족할 수 있다.

Drift 후보 판단 기준

KS 통계량이 관리 기준을 넘고 p-value가 작으며, ECDF 최대 차이 위치와 히스토그램 이동 구간이 같은 방향으로 설명될 때 단변량 feature drift 후보로 해석한다. 표본 수가 매우 크거나 다중 검정 상황이면 효과 크기와 보정 결과를 함께 확인한다.

이 예시 차트의 해석

이 예시에서는 KS 통계량이 0.217이고 근사 p-value는 <0.001이다. 따라서 기준 구간과 현재 구간이 같은 분포라는 가설을 기각할 근거가 강하다.

왼쪽 ECDF 패널을 보면 현재 구간의 붉은 CDF가 기준 구간의 파란 CDF보다 오른쪽으로 밀려 있다. 이는 현재 구간의 값이 기준 구간보다 전반적으로 커졌을 가능성을 보여준다.

오른쪽 히스토그램에서도 붉은 분포가 파란 분포보다 오른쪽 구간에 더 많이 분포한다. 따라서 이 예시는 단순한 p-value 신호가 아니라, 분포 위치 이동이 시각적으로도 확인되는 사례다.

보고서 문장 예시는 다음과 같다.

기준 구간과 현재 구간의 단변량 feature 분포를 KS Test 관점에서 비교한 결과,
KS 통계량은 0.217, 근사 p-value는 0.001 미만으로 나타났다.
ECDF와 히스토그램을 함께 보면 현재 구간의 분포가 기준 구간보다 오른쪽으로 이동한 패턴이 관측된다.
이는 해당 feature의 covariate shift 후보 신호로 해석할 수 있다.

금지해야 할 해석

이 차트만으로 다음을 단정하지 않는다.

금지 1
  - 모델 성능이 저하되었다.

금지 2
  - concept drift가 발생했다.

금지 3
  - 분포 변화의 원인이 특정되었다.

금지 4
  - 모든 feature 또는 전체 embedding distribution이 변했다.

KS Test는 단변량 분포 비교다. label 또는 ground truth 없이 성능 저하를 확정할 수 없고, 단일 feature 결과만으로 전체 데이터 구조 변화를 확정할 수도 없다.

추가 확인 항목

이 차트에서 drift 후보가 보이면 다음을 추가 확인한다.

  • 같은 기간의 data quality, missing rate, schema 변경 여부
  • 해당 feature의 단위, scaling, clipping, outlier 처리 변경 여부
  • 여러 feature를 동시에 검정했다면 다중 검정 보정 여부
  • 기간별 histogram 또는 ECDF trend
  • label 확보 후 성능 지표 변화
  • 다른 detector, 예: Wasserstein Distance, PSI, MMD, 와의 합의 여부

적합한 사용 대상

이 chart는 다음 method variant에 적합하다.

  • KS Test / ONE_SAMPLE_KS_KNOWN_CDF
  • KS Test / TWO_SAMPLE_KS_TWO_SIDED
  • KS Test / TWO_SAMPLE_KS_ONE_SIDED_GREATER
  • KS Test / TWO_SAMPLE_KS_ONE_SIDED_LESS
  • KS Test / TWO_SAMPLE_KS_EXACT_PVALUE
  • KS Test / TWO_SAMPLE_KS_ASYMPTOTIC_PVALUE
  • KS Test / KS_WITH_TIES_OR_DISCRETE_CAUTION
  • KS Test / LILLIEFORS_RELATED_ONE_SAMPLE
  • KS Test / HIGHER_ORDER_KS
  • KS Test / TWO_SAMPLE_KS_APPROX_QUANTILE

다만 one-sided 변종에서는 차트에 방향성 가설을 명시해야 한다. approximate 변종에서는 approximation error, quantile error, summary method를 caption 또는 보조 패널에 추가해야 한다.
